ÁUDIO DO COMPUTADOR

1. No app de desktop já funciona sozinho

Rodando como programa de computador (npm start ou o app instalado), ele capta direto tudo que sai das caixas, sem driver nenhum e sem passar pelo microfone. Na primeira vez o Mac pode pedir a permissão de gravação de tela (é só liberar; ele usa isso pra pegar o som do sistema, não pra gravar a tela). Funciona pra FL Studio, YouTube, Spotify, tudo.

Só precisa do passo a passo abaixo do BlackHole se abrir pelo navegador comum, ou se a captura nativa não pegar no seu Mac. É o plano B.

2. Plano B: instalar o BlackHole (uma vez só)

  1. Baixe em existential.audio/blackhole (versão 2ch).
  2. Abra o instalador e siga o padrão (vai pedir sua senha do Mac).

3. Criar a saída combinada (uma vez só)

  1. Abra o app Configuração de Áudio MIDI (busca no Spotlight: ⌘+espaço).
  2. Clique no + no canto inferior esquerdo → Criar dispositivo de múltiplas saídas.
  3. Marque BlackHole 2ch e a sua saída de som (fones ou caixas).
  4. Clique com o botão direito nesse dispositivo novo → Usar este dispositivo para saída de som.

Pronto: você continua ouvindo normal, e o BlackHole recebe uma cópia do som.

4. No FL Studio

Se o FL usa driver próprio de áudio, em Options → Audio Settings escolha o dispositivo de múltiplas saídas como saída. Apps comuns (YouTube, player) já seguem a saída do sistema, sem ajuste.

5. Pronto

Se a captura nativa não pegar, o app cai pro BlackHole sozinho e começa a ouvir o dispositivo de múltiplas saídas.
